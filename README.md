# Phase_Transition_Z2_LGT
MCMC simulation and data analysis code for a) simulating a Z2 Lattice Gauge Theory and b) Analyzing the phase transition
The following folder contains the following code (Initially based on Creutz's code in https://www.latticeguy.net/mypubs/pub165.pdf 'Simulating Quakrs"):

1) Run a Z2 Lattice Gauge Theory (in Parallel) with Metropolis and or Heatbath updates
2) Run a Multicanonical weight sampling procedure and then the respective Multicanonical simulation
3) Statistics on the raw avg plaq data to compute observables (avg plaq,plaq sus, binder)
4) FS Reweighting for statistics at different couplings as well as for Multicanonical simulations
5) Analysis of Susceptibility and Binder curves to compute peak/valley information 
6) Finite size scaling analysis
